# USD/LKR & Gold Price Tracker Dashboard

An interactive Streamlit web application that tracks weekly USD to LKR exchange rates and global Gold Futures rates using Yahoo Finance data.

## Features
- Dynamic background video styling for modern UI.
- Real-time or historical data extraction via `yfinance`.
- Comparative data viewer and key financial metrics display.
- Visual charts comparing USD/LKR and Gold trends over time.
